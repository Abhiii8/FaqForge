END-TO-END WORKFLOW

Architectural Inference Pipeline

How FAQForge transforms unstructured documents into verifiable knowledge without cloud latency or hallucinations.

STAGE 01

Structural Ingestion

PyMuPDF and python-docx extract text page-by-page, detecting heading hierarchies and preserving structural citations.

STAGE 02

Semantic Inventory

spaCy NER extracts key entities while TF-IDF vectorizers score high-value domain keywords to formulate question targets.

STAGE 03

Local Ollama Qwen2.5

Qwen2.5 3B generates abstractive question-answer pairs using temperature 0.2 and structured JSON schema enforcement.

STAGE 04

Grounded Verification

The verification engine validates numbers, dates, and lexical root overlaps, pruning duplicates via Jaccard token similarity.
